All what you must do is download Fastled in Arduino IDE and replace W-LAN Name with the name from your WiFi,replace W-LAN Passwort with you passwort from the wifi
The ESP 32 dont know at the moment on which Pin you LED is and how many LED at count there are. You must replace the numbers here -> 
#define LED_PIN 27          
#define NUM_LEDS 58
